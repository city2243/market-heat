# Market Heat

台灣、美國、日本公司營運與產業新聞的 GitHub Pages 公開入口。

## 架構

`index.html` 嵌入現有公開新聞服務，並提供全螢幕連結。這不是完整後端遷移：新聞收錄、翻譯、品質檢查、股價、歷史資料及更新 API 仍由原服務負責。

原服務：https://market-heat-jaime.jaime2243.chatgpt.site

讀者不需要 GitHub 帳號。實際新聞時間以原服務的資料截止時間為準；GitHub 提交或部署時間不代表新聞已更新。入口每次開啟均載入原服務，不另建立新聞排程。

## 部署

GitHub Pages 從 `main` 分支根目錄發布。修改入口後自動部署。

## 安全與限制

此儲存庫只含公開入口，不含登入資訊、API 密鑰、原站私有設定或後端憑證。若瀏覽器不顯示內嵌頁面，使用全螢幕閱讀連結。
